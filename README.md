# Todo List

Projeto simples de lista de tarefas, usado como exemplo no minicurso de **Git para iniciantes**.

Feito com HTML puro e [Tailwind CSS](https://tailwindcss.com/) (via CDN) — arquivo único, sem build, sem dependências para instalar.

## Funcionalidades

- Adicionar tarefas através de um input + botão
- Remover tarefas da lista
- Estado vazio quando não há tarefas

## Como rodar

Abra o arquivo `index.html` no navegador:

```bash
open index.html
```

Ou simplesmente dê dois cliques no arquivo.

## Estrutura

```
.
├── index.html   # página da aplicação (HTML + Tailwind + JS)
├── logo.svg     # logo exibida no topo
└── README.md    # este arquivo
```

## Tecnologias

- HTML5
- Tailwind CSS (CDN)
- JavaScript (vanilla)
